# Bambaura 9X Storefront

A responsive, premium editorial storefront starter built with React, Tailwind CSS, HTML, jQuery, GSAP + ScrollTrigger, and Framer Motion.

## Run locally
1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Production build
- `npm run build`
- `npm run preview`

## Stack notes
- **Tailwind CSS** provides the utility CSS pipeline; `src/styles.css` adds bespoke responsive brand styling.
- **GSAP + ScrollTrigger** animates the hero and reveals sections as they enter the viewport.
- **Framer Motion** powers the interactive product cards, search panel, product modal, cart drawer, and notifications.
- **jQuery** provides small namespaced navigation hover interactions.
- **Lucide React** provides lightweight interface icons.

## Before launch
- Product descriptions, pricing, shipping threshold, and mineral claims are demonstration content. Verify them against approved brand information.
- Cart and checkout are front-end demo interactions. Connect Shopify Storefront API or your preferred commerce backend for real inventory, checkout, tax, and order processing.
- Replace any generated/mockup imagery with approved production photography if needed.
